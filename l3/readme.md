# 트래픽 분류 모델 성능 향상

  - 모델 학습 시 동일한 데이터셋 적용  
  - random_state 값 고정

  -  Way#1: 하이퍼파라미터 튜닝  
    - n_estimators 조정: 분류 모델을 통해 구분할 label 갯수를 예상되는 값보다 높게 설정한 것으로 보임

  - Way#2: 학습데이터 특성(feature) 추가  
    - port 번호: 일부 프로토콜은 사용 port 범위, 규칙 발생  
    - protocol 코드: 패킷 통신에 활용된 프로토콜의 범주 값. 프로토콜 구분만으로도  있을 것이란 가설
